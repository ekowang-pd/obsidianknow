# Deer Notes 0.3.4

Folder views now include Markdown, HTML, and local image files. Images open in a large preview; HTML opens in a script-free reading view. Markdown and HTML can be edited and saved directly from the reader. Saving checks whether the file changed elsewhere first, so a stale editor cannot silently overwrite newer content. The All notes view remains focused on Markdown notes.

The browser demonstration covers folder browsing, image and HTML previews, and Markdown/HTML save and refresh. Native Obsidian themes, mobile behavior, and large vault performance still need direct user acceptance after installation.
