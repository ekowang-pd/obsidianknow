# 一期：把摘录变成自己的理解

日期：2026-09-12。状态：开发完成，待真实 Obsidian 验收。当前为本地预览，非市场发布版本。

## 目标与范围
围绕“阅读 → 摘录 → 自己解释 → 对照原文 → 保存”的短流程，帮助用户留下自己的表达。面向现有个人知识库，不要求更改文件夹结构。

| 编号 | 一期功能 | 可验收行为 |
| --- | --- | --- |
| P1-01 | 原文与理解分区 | 原文只读，自己的笔记独立输入，保存时保留来源 |
| P1-02 | 隐藏原文后复述 | 隐藏与显示可随时切换，输入和实际保存的摘录不受影响 |
| P1-03 | 三个可选思考角度 | 我的理解、已有联系、尝试应用；点击显示具体问题并插入 Markdown 标题 |
| P1-04 | 继续已有思考 | 重复点击定位到已有小节，中英文标题视作同一种提示，不覆盖原文和草稿 |
| P1-05 | 顺畅保存 | Ctrl/⌘+Enter 保存，输入法组合输入不触发；保存期间禁用操作，失败保留草稿并允许重试 |

自由记录始终可用。提示只提供问题和标题，不代写解释，不以标题数判断掌握情况。后台提醒、回顾队列、知识图谱、自动分类与 AI 生成不属于一期。

## 数据与交互
复用现有摘录服务与普通 Markdown，不引入数据迁移或网络请求。隐藏原文仅改变当前对话框显示，不删除内容。取消沿用既有关闭行为；当前草稿不承诺跨关闭或重启恢复。

键盘焦点限制在摘录对话框内；隐藏按钮标明展开状态。界面中英文切换不翻译用户输入；同类提示可识别中文和英文标题。移动端继续使用可滚动弹窗，真实设备未验证。

## 验收路径
1. 从列表打开一篇文章，选中一段原文，点击“做笔记”。
2. 点击“隐藏原文，试着复述”，输入自己的解释；再显示原文核对。
3. 点击三个思考角度；回点“我的理解”，应回到该段继续输入，而不是追加重复标题。
4. 用 Ctrl/⌘+Enter 保存；打开保存的 Markdown，核对原文、解释和来源。
5. 在预览设置模拟保存失败，确认草稿保留并可重试。原文隐藏状态也应保留。

## 自检证据与限制
146 项测试通过，覆盖正文与来源不变、隐藏原文、组合输入、快捷保存、跨语言标题去重和光标定位，既有失败恢复与焦点限制测试通过。类型检查和构建结果随本轮任务记录。没有真实学习效果数据，不声称已经改善记忆或认知。

补充验收：隐藏摘录时同时隐藏背景阅读正文，显示原文或关闭摘录窗口后恢复。最终 146 项测试、类型检查、插件与预览构建、发布文件检查通过。浏览器已检查摘录弹窗与隐藏入口；真实 Obsidian 和移动端仍待验收。
