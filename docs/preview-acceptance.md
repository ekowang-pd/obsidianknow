# 小鹿笔记 0.1.0 预览验收

预览标签：`0.1.0-preview.2`。插件内部版本：`0.1.0`。

## 安装

1. 使用一个独立的 Obsidian 测试库。
2. 将预览产物 `main.js`、`manifest.json` 和 `styles.css` 放入测试库的 `.obsidian/plugins/deer-notes/`。
3. 在 Obsidian 第三方插件中启用 Deer Notes，执行命令“Deer Notes: 打开小鹿笔记”。
4. 从旧版升级时替换三项产物，再重新加载插件。

## 本次修复

摘录保存期间取消、按 Escape、关闭阅读器或切换文档，以前会丢弃编辑器。如果后台写入随后失败，草稿丢失且没有错误提示。

现在写入期间保留编辑器，显示“正在保存，请稍候…”，并暂时阻止这些关闭操作。写入成功后关闭编辑器；失败后保留原文、笔记文字和错误信息，恢复编辑与重试。插件卸载仍会释放资源；本次没有加入关闭整个工作区或退出应用后的持久草稿恢复。

## 验收项目

- 空白库打开看板后，不自动创建“小鹿笔记”目录。
- 输入一条快速笔记并保存，确认文件为普通 Markdown，且看板出现记录。
- 插入图片并保存，确认阅读器和 Obsidian 原生阅读均可显示图片。
- 打开一篇 Markdown，选取正文并点击“做笔记”，保存后确认原文没有改变。
- 对同一来源当天再次摘录，确认追加到同一篇笔记，来源链接可跳回原文。
- 保存期间不能通过取消、Escape 或阅读器关闭入口丢弃正在保存的摘录。
- 写入失败后原文与草稿仍在，错误清晰可见，恢复可写后可以重试。
- 新建、重命名一级目录，确认导航即时更新。
- 明暗主题中检查文本、工具栏、选文菜单和窄窗口布局。

延迟写入和失败重试由自动回归测试验证；不要在真实知识库中故意制造磁盘故障。移动端和第三方主题另行验收。
